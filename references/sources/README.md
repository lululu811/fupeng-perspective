# 素材目录说明

由于版权和体积原因，`references/sources/` 下的原始素材**不包含在本开源仓库中**。

该目录结构如下：

```
sources/
├── books/          # 书籍章节（164 篇）
├── articles/       # 专栏文章（245 篇）
└── transcripts/    # 演讲/访谈文字稿（442 份）
```

## 如何获取素材

如需用于学术研究或个人学习，你可以：

1. **自行收集**：通过公开渠道（B站、小宇宙播客、付鹏专栏等）获取
2. **联系作者**：通过 GitHub Issues 联系本项目维护者
3. **使用调研结果**：`references/research/` 下的 6 维度调研文档已经提炼了核心内容，通常无需原始素材

## 素材格式

- 书籍：Markdown 格式，按日期编号
- 文章：Markdown 格式，来源于 V 专栏等
- 演讲/访谈：AI 转录的 Markdown 文字稿，来源于 B 站、播客等
