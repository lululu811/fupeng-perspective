### 决策1: 预判2024年英伟达"爆金币"（经典战役）
- **时间**: 2024年5-6月（提前约1.5-2个月预警）
- **背景**: 英伟达市值约3万亿美元，市场波动率极低（VIX处于历史低位），场外杠杆规模庞大（估计8000亿-9000亿美元）
- **决策逻辑**:
  1. 波动率是确定性的反向指标——波动率极低意味着确定性极高，确定性极高会诱发贪婪和杠杆堆积
  2. 新加坡调研发现场外杠杆规模远超公开数据，"各家统计的只是各家的，谁知道总量有多少，你只能打听"
  3. 市场集中度从标普500缩圈到100，再到七姐妹，再到英伟达一家，"缩圈缩到决赛圈"
  4. 市盈率接近38倍（接近2021年木头姐泡沫峰值），"不能出现任何miss"
  5. 提出"淘金小镇"隐喻：卖铲子（英伟达）和挖金矿（应用端）的关系，铲子卖不动时整个链条会断裂
  6. 建议机构"买保险"（买入VIX看涨期权）进行对冲
- **结果**: 2024年8月英伟达闪崩，全球股市暴跌。**判断正确**
- **事后反思**: 
  - 明确否定"日元套息交易拆仓导致暴跌"的主流解释，指出是"资产端引发的，不是负债端引发的"
  - 强调"英伟达依旧伟大"与"股价因杠杆过高产生剧烈波动"是两个维度的问题
  - 提出"爆完金币就是捡尸体"的后续策略——暴跌后反而应该买入核心资产
  - 公开承认"猜不到什么时候会出问题"，但通过波动率指标识别了风险区间
- **置信度**: 🟢
- **过程密度**: 高（提前预警、事中跟踪、事后复盘完整链条）

### 决策2: 2024年4月关税事件抄底美股
- **时间**: 2024年4月（对等关税发布期间）
- **背景**: 市场对关税恐慌，VIX飙升至高位
- **决策逻辑**:
  1. 交易员思维vs研究员思维的区别——"研究员等关税落地再做交易，黄花菜都凉了"
  2. "有人放牌这种事只要出来就可以反转了，就不用再去管关税这件事"
  3. 事件波动率峰值就是反向信号——"别人恐慌的时候我贪婪"
- **结果**: 抄底时机精准，此后美股持续创新高。**判断正确**
- **事后反思**: 在后续访谈中多次将此作为"确定性vs不确定性"的经典案例
- **置信度**: 🟢
- **过程密度**: 高

### 决策3: 2015年A股股灾前躲避（约1个月前撤离）
- **时间**: 2015年中（股灾前约1个月）
- **背景**: A股杠杆牛疯狂，场外融资配资盛行
- **决策逻辑**:
  1. 在香港工作期间观察到场外杠杆堆积的异常信号
  2. "老狐狸的敏感性"——对高杠杆低波动组合的危险本能警觉
  3. 2016年开始的"付鹏说"第一季内容即围绕如何避开2015年股灾展开
- **结果**: 成功躲避股灾。**判断正确**
- **事后反思**: 
  - 承认"最后一波疯狂的时候往往没我们什么事"——"我也赚不到最后那把疯狂，但我一定能躲过疯狂后的暴跌"
  - 提到一个朋友"all in梭哈，把结婚买房钱全部投进去，加20倍杠杆，一夜白头，穿仓倒欠证券公司和交易所的钱"
  - 核心原则："活得长比一时爽重要得多"
- **置信度**: 🟢
- **过程密度**: 中（ retrospective 描述为主）

### 决策4: 2012年布局日元贬值交易（提前捕捉日本转折）
- **时间**: 2012年初
- **背景**: 日本福岛核泄漏后，市场普遍认为日本资产不可碰，但巴菲特于2011年底秘密造访日本
- **决策逻辑**:
  1. 从索罗斯基金控制人本森特经香港转机去日本的情报中捕捉信号
  2. "聪明比你聪明、比你段位高很多的人做出行为动作时，不是在网上喷他SB，而是思考他为什么这么做"
  3. 预判安倍上台后将推动日元大幅贬值+对内改革+对外全球再分工
  4. 通过贸易渠道（花王纸尿裤）实现日元套利，而非单纯的金融衍生品
- **结果**: 日元从2012年开始持续贬值至今，日本股市以美元计价持续走高。**判断正确**
- **事后反思**: 
  - 提出日本不是"失去的三十年"而是"对内分配+对外分工"的结构性调整
  - 预判日本股市将成为"美股的影子"，波动率更大但节奏一致
  - 日元汇率锚定在151-153水平（2022年10月形成）
- **置信度**: 🟢
- **过程密度**: 高（12年持续跟踪验证）

### 决策6: 2024年9月中国政策转折点——"越差越转折"判断
- **时间**: 2024年8-9月
- **背景**: 中国经济面临多重压力，10年期国债收益率触及2%，收益率曲线后端极度平坦
- **决策逻辑**:
  1. 国债收益率曲线后端平坦化是"死亡螺旋"信号——市场完全失去了中长期预期
  2. "在那种转折点上，越差越转折"——经济越差，倒逼政策出台的迫切性越高
  3. 9月11日发表政策建议日记："一定要防止经济现在断崖，尽快出政策对冲"
  4. 8-9月密集发声讨论经济压力，判断这是"上面要做调研了解"的信号窗口
  5. 判断政策方向将是"止和稳"——阻止资产负债表螺旋式收缩，稳定市场预期
- **结果**: 9月24日政策组合拳出台，A股暴涨。**判断正确**
- **事后反思**:
  - 明确自己身份从"投资者"切换为"有官方身份的政策建言者"
  - 承认"被当枪使"但也认为"这就是你的duty，你的职责就是干这个"
  - 提醒不要重蹈2015年覆辙："不要让大家搞成15/16年的代价"
  - 预判经济验证要到"明年春节后"才会逐渐讨论"证伪"
- **置信度**: 🟢
- **过程密度**: 高

### 决策7: 2024年11月特朗普当选后的政策预判
- **时间**: 2024年11月7日（大选结果出炉当晚应急直播）
- **背景**: 特朗普横扫参众两院再次当选
- **决策逻辑**:
  1. 地缘政治风险减弱（特朗普"事不关己高高挂起"的商人思维）
  2. 中国政策重心将从"外围防御"转向"对内刺激"——财政空间打开
  3. "你打外围我打外围，你打经济我打经济"——政策对冲的打牌逻辑
  4. 人民币汇率贬值将作为对冲关税的工具（"从一张坏牌变成好牌"）
  5. 预判特朗普政策组合（加关税+减税+控移民）将导致美国通胀韧性持久
  6. "不排除美联储被迫重新加息的可能性"——市场没人敢想
  7. 巴菲特减持苹果持有现金的逻辑："确定性收益（4%+利率）vs不确定的业绩增长"
- **结果**: 后续中国政策确实转向对内刺激，军工板块下跌、内需板块上涨，与预判一致。**判断正确**
- **事后反思**: 提醒"不能放松警惕"——特朗普第二任团队比第一任更强，且参众两院横扫减少了制衡
- **置信度**: 🟢
- **过程密度**: 高

### 决策8: 中国A股"哑铃策略"持续判断（2023-2025）
- **时间**: 2023年至今
- **背景**: 中国经济进入风险偏好长期下降周期
- **决策逻辑**:
  1. 提出"分子-分母-治理因子"三维分析框架
  2. 哑铃一端：低风险偏好的类现金资产（央国企红利、水电煤油气等垄断公用事业）
  3. 哑铃另一端：高风险偏好的小盘微盘投机（政策兜底下的"YOLO"博弈）
  4. "两头都对"的逻辑——差差不到哪去（政策兜底），好好不到哪去（基本面未扭转）
  5. 预判"哑铃转折点还没到"，直到春节后才开始讨论证伪
- **结果**: 截至2025年8月，哑铃结构仍然共存。**判断持续验证中**
- **事后反思**: 承认个人选择偏向低风险端——"通缩下购买力在增强，核心是不逐本"

### 决策9: 中国房地产判断——"房住不炒"后的资产负债表收缩
- **时间**: 2018年至今持续跟踪
- **背景**: 房地产从金融资产回归居住属性
- **决策逻辑**:
  1. 2018年年中居民部门加杠杆到达极限——"债务压力大于可承受能力和范围"
  2. 房价停止加速上涨后进入"资产负债表螺旋式循环"——越缩、需求越缩、供给越过剩
  3. "不敢让房地产出问题"的困境——因为出不起这个代价，所以问题越积越大
  4. "万事万物皆有利和弊"——房地产跌的时候，没买房的人乐呵，买了房的人收缩
  5. 发现"我的朋友"的新型套利模式：吃入核心资产+经营贷利差+美元定存+汇率收益（年化约8%）
  6. 预判一线城市核心区限购取消后，富人将利用"借人民币carry美金"的倒过来套息交易
- **结果**: 房地产持续收缩，居民部门资产负债表持续受损。**判断正确**
- **事后反思**: 多次强调"不能让房地产出问题"是大而不倒的逻辑，但"人人之初性本贪"导致问题持续累积
- **置信度**: 🟢
- **过程密度**: 高

### 决策10: 比特币定位的演变——从"纯分母资产"到"分子端利率"
- **时间**: 2021-2025年
- **背景**: 比特币经历多轮牛熊
- **决策逻辑演变**:
  1. 早期（2021年前）：定义为"纯分母资产"——纯利率逻辑，木头姐被干后比特币大跌
  2. 中期（2022-2023）：发现"利率高了但比特币还涨"，开始修正观点
  3. 最新（2024-2025）：重新定位为"分子端上的利率"——即估值，内核是AI/人工智能叙事
  4. "当它跟AI关联上了，分子端就在它身上"——所以利率高也能涨
  5. 但警告：如果AI叙事与比特币脱钩，它将回归"纯分母"
  6. 加密货币纳入储备资产是"巨变"——"不是回到过去，而是朝向未来"
  7. 核心洞察：加密货币的本质是"中心化"而非"去中心化"——"去的是别人的中心化"
- **结果**: 比特币在2024-2025年持续走高，与AI叙事深度绑定。**判断持续验证中**
- **事后反思**: 公开承认早期认知局限——"5-6年前单独认为它就是虚拟性资产，这个定义在当时是对的，因为它确实没有展现出现在的情况"
- **置信度**: 🟢
- **过程密度**: 中（公开修正过观点，体现了认知迭代）

## 言行一致/不一致分析

### 高度一致的领域
1. **"活得长比一时爽重要"** → 行动上：2015年躲股灾、2024年躲英伟达暴跌、策略上倾向"越涨越减"
2. **波动率是核心观察指标** → 持续使用VIX作为风险温度计，两次经典交易均围绕波动率展开
3. **"前瞻性考虑3-6个月"** → 付鹏说用户总结"副总说完一件事别着急，过一段时间才会发生"
4. **调研驱动决策** → 去日本→预判安倍经济学；去新加坡→发现英伟达杠杆异常；去越南/澳洲→持续跟踪
5. **"站在巨人肩膀上"** → 跟踪巴菲特、索罗斯等顶级投资者的行为作为先行信号

### 需要关注的潜在不一致
1. **"不关心短期涨跌"** vs 频繁进行短期波动率交易（可能只是周期定义不同）
2. **"不预测具体时点"** vs 多次精准踩点（2024年4月、9月、11月）——可能是"不预测"但"准备好了就行动"
3. **公开分析框架非常系统化** vs 自称"老狐狸的敏感性"——暗示存在大量未公开的经验直觉

## 决策风格特征

### 核心方法论
1. **波动率观察法**：低波动率+高集中度=危险信号；高波动率=机会信号
2. **缩圈理论**：市场资金从分散到集中，缩到核心再到内核，杠杆堆积到极点时崩溃
3. **分子-分母-治理因子框架**：将资产按风险偏好分为三类（类现金/经济关联/纯估值）
4. **大类资产串联**：汇率-利率-权益-商品之间的联动关系
5. **行为金融学视角**：用"卖保险vs买保险"理解结构化产品，用"捡尸体"理解暴跌后的机会
6. **政治-经济-市场金字塔**：意识形态→政治→政策→经济→市场，自上而下分析

### 决策节奏
- **前瞻窗口**: 3-6个月
- **行动触发**: 重大转折点前后（平时"半退休状态"）
- **持仓风格**: 不追最后一波，提前减仓拿现金，暴跌后加仓
- **信息渠道**: 社交调研>电脑数据，"老板应该举着红酒雪茄社交"

### 风险管理
- **核心原则**: "不逐本"——通缩环境下保住本金就是赢
- **对冲工具**: VIX期权（"买保险"）
- **仓位管理**: 估值越高仓位越低，与趋势跟踪者相反
- **止损逻辑**: 不是价格止损，而是"波动率逻辑被打破"时离场
